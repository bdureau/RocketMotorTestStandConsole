Test Stand Help File

This is a quick help file to use your Test Stand application. The Test Stand application is a very convenient way to record your motor thrust curves when you are on the field.

Initial Setup & Bluetooth Pairing

  1. Firmware Compatibility: Make sure that your Test Stand board is compatible (i.e. the correct firmware has been loaded).
  2. Module Connection: Make sure that the Bluetooth module is connected to the Test Stand board.
  3. Pairing in System: Go to your Android device settings, open Bluetooth configuration, and search for the HC-05, HC-06, or other Bluetooth module. Enter the pairing PIN code (default is 1234).
⚠ CAUTION
Clearly name each paired Bluetooth device in your phone to make sure you configure the correct test stand.
  1. Power On: Turn on the Test Stand and wait until it stops beeping.
  2. Connect: Start the application on your Android device, tap "Show paired devices", and select your HC-05 or HC-06 module. The console will now attempt to connect.

Once connected, you can use the application to configure your Test Stand or read recorded thrust curves. If it cannot connect, verify that the board is powered on and that the correct Bluetooth adapter is selected.

Using the Test Stand Application

Main Screen Actions

[Test Stand Setting]

Reads the current Test Stand configuration and allows you to modify it.

[Read Thrust Curves]

Reads all recorded motor thrust curves from memory and plots them as interactive graphs.

[Telemetry]

Opens real-time telemetry streaming from the test stand.

[Reset Settings]

Restores factory default parameters. Also allows clearing all stored thrust curves.

[Status]

Opens the hardware diagnostics screen displaying sensor health, battery voltage, and board state.

[Flash Firmware]

Allows updating board firmware directly via a USB cable.

[Connect / Disconnect]

Establishes or terminates communication with the Test Stand.

Main Screen Menu

From the options menu, you can open this help guide, access the "About" screen displaying version metadata, and customize the visual appearance of the application.

Supported Hardware

This application supports the following Test Stand controller boards:

• Test Stand ATmega328

This is the original test stand prototype that I did using an ATmega328

• Test Stand STM32 (Version 1)

This is the first production test stand with a STM32 board. It has only one input for the gauge sensor so it is only able to measure thrust

• Test Stand STM32 (Version 2)

This is the second version of the test stand, it also uses an STM32 board. It has an input fo the gauge sensor to measure thrust and 2 analog inputs for the measuring the pressure inside the casing

• Test Stand ESP32 (Version 3)

This is the third version of the test stand, it uses an ESP32 chip. It has an input fo the gauge sensor to measure thrust and 2 analog inputs for the measuring the pressure inside the casing. Note that for some reason it records less
