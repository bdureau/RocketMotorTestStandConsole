Flashear Firmware

En primer lugar, debe seleccionar el firmware. El firmware depende de la placa del banco de pruebas que desee actualizar.

Luego decida si desea flashear directamente el firmware operativo o utilizar un firmware de recuperación previamente.

Firmware de recuperación: Utilice un firmware de recuperación si la configuración está dañada y el banco de pruebas ya no puede conectarse. Después de cargarlo, deberá flashear de nuevo el firmware operativo.
⚠ PRECAUCIÓN
Flashear un firmware erróneo provocará que el banco de pruebas no funcione en absoluto o se comporte de manera impredecible.

Material necesario

Para flashear su banco de pruebas necesitará un cable conversor USB-TTL y un adaptador OTG (USB-C o Micro-USB) para conectarlo a su teléfono o tableta Android.

Bancos de prueba compatibles

Observe con atención las imágenes siguientes para identificar su modelo:

• Banco de pruebas ATmega328 (versión grande)

• Banco de pruebas STM32 V1

• Banco de pruebas STM32 V2

• Banco de pruebas ESP32

Instrucciones según el microcontrolador

Como alternativa, puede intentar realizar una detección automática del firmware.

1. Bancos de prueba basados en ATmega328

  • Conecte el cable USB.
  • Seleccione el firmware correcto o utilice la detección automática.
  • Presione y suelte el botón de reset en el banco de pruebas y pulse el botón [Flash Firmware].

2. Bancos de prueba basados en STM32

  • Conecte el cable USB.
  • Seleccione el firmware correcto o utilice la detección automática.
  • Mueva el puente BOOT0 hacia la derecha (modo programación):

  • Presione el botón de reset en la placa.
  • Pulse el botón [Flash Firmware].
  • Una vez completada la carga, regrese el puente BOOT0 hacia la izquierda (modo normal):

  • Presione el botón de reset para reiniciar el banco de pruebas.

3. Bancos de prueba basados en ESP32

  • Conecte el cable USB.
  • Seleccione el firmware correcto o utilice la detección automática.
  • Mantenga presionado el interruptor superior:

  • Presione y suelte brevemente el interruptor inferior manteniendo pulsado el superior:

  • Suelte finalmente el interruptor superior.
  • Pulse el botón [Flash Firmware].
⚠ NOTA IMPORTANTE
Nunca desconecte el cable durante el proceso de flasheo para evitar corromper la memoria.
