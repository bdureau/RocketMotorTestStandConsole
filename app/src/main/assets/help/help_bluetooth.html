Select Bluetooth Module

You will be prompted to choose a Bluetooth module if you have not selected one already or if you want to connect to a different Test Stand.

Pairing & Selection Procedure

  1. Pairing in System: First, pair all your Bluetooth Test Stand modules in your Android device's Bluetooth settings (default pairing PIN code is usually 1234 or 0000).
  2. Select Module: From the list of configured modules, select the one your Test Stand is using.
  3. Reconnect: Leave the screen and initiate the connection again. If you have chosen the wrong module or the board is off, the connection will fail.
⚠ IMPORTANT ADVICE
Make sure that you clearly differentiate and rename your Bluetooth devices on your phone so that you always connect to the correct Test Stand.
