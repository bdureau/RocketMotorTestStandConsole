Configuration d'un module Bluetooth

De manière à pouvoir configurer un module Bluetooth pour connecter un altimètre à votre téléphone, vous aurez besoin de le régler afin qu'il fonctionne à la même vitesse que votre carte altimètre.

Cet écran vous permettra de paramétrer des modules compatibles tels que les HC-05, HC-06, etc.

Matériel requis

  • Un câble adaptateur USB-Série TTL.
  • Un adaptateur USB (USB-C ou Micro-USB suivant votre appareil Android).
  • Un adaptateur JST et des câbles JST.

Harmonisation de la vitesse (Baud Rate)

Notez que ces modules sont en général préconfigurés à 9600 bauds. Cependant, votre altimètre par défaut est configuré à 38400 bauds. Il faudra donc vous assurer d'ajuster cette vitesse pour correspondre à votre carte.

⚠ ATTENTION
Assurez-vous de ne pas débrancher le module ni le câble lorsque vous effectuez les opérations suivantes.

Procédure de configuration

  1. Connexion : Raccordez le module à votre appareil Android en utilisant un câble TTL et un adaptateur USB OTG.
  2. Choix du module : Sélectionnez le modèle de module Bluetooth que vous possédez. Si vous ne savez pas lequel vous avez, choisissez celui par défaut ou un profil compatible. Si aucun ne fonctionne, envoyez-nous des photos et les références du module.
  3. Charger la configuration : Cliquez sur [Charger cfg]. L'application tentera de se connecter à la vitesse par défaut de 38400 bauds. Si cela échoue, réessayez : elle testera plusieurs débits jusqu'à établir la liaison et charger les paramètres.
  4. Sauvegarder la configuration : Modifiez les paramètres souhaités (nom du module, code PIN, vitesse). Assurez-vous d'avoir choisi une vitesse compatible avec votre carte (en général 38400 bauds) et cliquez sur [Sauver cfg]. En cas d'erreur lors de l'enregistrement, l'opération sera annulée.
Remarque : Il sera nécessaire de répéter cette procédure pour chaque module Bluetooth que vous souhaitez configurer.
