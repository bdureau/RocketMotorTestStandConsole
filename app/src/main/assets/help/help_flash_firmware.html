Flash Firmware

First, you need to select the firmware. The firmware depends on the specific Test Stand board you want to flash.

Then decide if you want to directly flash the operational firmware or use a recovery firmware first.

Recovery Firmware: Use a recovery firmware if the board configuration is corrupted and the Test Stand can no longer connect. After loading a recovery firmware, you will need to re-flash the operational firmware.
⚠ CAUTION
Flashing the wrong firmware will result in a Test Stand not working at all or not behaving as expected.

Required Hardware

To flash your Test Stand, you will need a USB-TTL cable and an OTG adapter (USB-C or Micro-USB) to connect it to your Android device.

Supported Test Stands

Please examine the pictures below carefully to identify your Test Stand board:

• ATMega328 Test Stand (the prototype) (Large version)

• STM32 Test Stand V1

• STM32 Test Stand V2

• ESP32 Test Stand V3

Flashing Instructions by Board Architecture

Alternatively, you can attempt to automatically detect the connected firmware.

1. ATMega328 Based Test Stand

  • Connect the USB cable.
  • Select the correct firmware or auto-detect it.
  • Press and release the reset button on the Test Stand, then tap the [Flash Firmware] button.

2. STM32 Based Test Stand

  • Connect the USB cable.
  • Select the correct firmware or auto-detect it.
  • Move the BOOT0 jumper to the right (programming position):

  • Press the reset button on the board.
  • Tap the [Flash Firmware] button.
  • Once loading is complete, move the BOOT0 jumper back to the left (normal run position):

  • Press the reset button to restart the Test Stand in normal mode.

3. ESP32 Based Test Stand

  • Connect the USB cable.
  • Select the correct firmware or auto-detect it.
  • Press and hold the top switch:

  • Press and release the bottom switch while continuing to hold the top switch:

  • Release the top switch.
  • Tap the [Flash Firmware] button.
⚠ IMPORTANT NOTE
Never disconnect the cable during flashing. Doing so will corrupt the firmware and require re-flashing from scratch.
