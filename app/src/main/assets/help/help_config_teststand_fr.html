Configuration du banc de test

La configuration du banc de test est répartie sur 2 écrans. Lorsque vous ouvrez chaque écran, vous êtes connecté au banc de test et consultez la configuration stockée dans sa mémoire embarquée.

État de la liaison : Assurez-vous que le banc de test est sous tension et appairé en Bluetooth ou USB avant de modifier les réglages.

Configuration du banc de test (Page 1)

Baud Rate : Permet de changer la vitesse de communication du banc de test (redémarrage de la carte nécessaire).

Résolution du banc de test : Fréquence d'échantillonnage et précision des mesures (nombre de mesures par seconde).

Capacité EEPROM : Permet de définir la taille de la mémoire EEPROM disponible sur la carte.

Durée d'enregistrement : Permet de définir la durée maximale d'enregistrement d'une courbe en secondes.

Type de batterie : Définit le type d'accumulateur utilisé pour avertir lorsque la tension d'alimentation chute.

Configuration du banc de test (Page 2)

  • Informations du firmware : Récupère et affiche la version du logiciel embarqué et le type de matériel.
  • Unités du banc de test : Permet de choisir les unités de mesure (métriques ou impériales).
  • Calibration du capteur : Permet d'étalonner la jauge de contrainte / capteur d'effort à l'aide d'une masse connue.
