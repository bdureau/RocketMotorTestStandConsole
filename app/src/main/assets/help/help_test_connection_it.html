Test della connessione

Questa schermata consente di testare l'affidabilità della connessione, in particolare con i moduli di telemetria 3DR. Mostra il numero di pacchetti persi a causa di una cattiva ricezione o di un segnale debole.

Suggerimento operativo: Esegui una verifica di copertura sul banco di prova prima di avviare il test statico del motore per accertare un adeguato margine di segnale.

Metriche analizzate

Pacchetti inviati / ricevuti: Conteggio totale dei frame di test scambiati sulla linea attiva.

Pacchetti persi: Numero di pacchetti non confermati a causa di interferenze RF, orientamento errato delle antenne o portata al limite.

Tasso di perdita (%): Percentuale di pacchetti persi rispetto al totale inviato. Un valore ridotto assicura una ricezione continua e senza interruzioni.

⚠ AVVISO PRE-TEST
Non eseguire il test del motore in caso di frequente perdita di pacchetti. Ciò indica interferenze elettromagnetiche locali, polarizzazione errata delle antenne o alimentazione insufficiente del ricetrasmettitore.
