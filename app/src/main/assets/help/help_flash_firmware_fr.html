Flashage du Firmware

Vous devez en premier lieu choisir le firmware à flasher. Le firmware dépend de la carte du banc d'essai à mettre à jour.

Décidez ensuite si vous souhaitez directement flasher la carte ou utiliser un firmware de récupération au préalable.

Firmware de récupération : Utilisez un firmware de récupération si la configuration du banc de test est corrompue et que celui-ci ne parvient plus à se connecter. Après avoir chargé un firmware de récupération, vous devrez reflasher le firmware opérationnel.
⚠ ATTENTION
Flasher votre banc d'essai avec un mauvais firmware aura pour conséquence un dysfonctionnement total ou un comportement imprévisible.

Matériel requis

Pour pouvoir flasher votre banc de test, vous aurez besoin d'un câble USB-TTL et d'un adaptateur OTG (USB-C ou Micro-USB) pour le relier à votre téléphone ou tablette.

Instructions de flashage par microcontrôleur

Vous pouvez également tenter une détection automatique du firmware.

1. Bancs de test à base d'ATmega328

  • Branchez le câble USB.
  • Choisissez le firmware approprié ou lancez la détection automatique.
  • Appuyez puis relâchez le bouton reset du banc de test, puis appuyez sur le bouton [Flash Firmware].

2. Bancs de test à base de STM32

  • Branchez le câble USB.
  • Choisissez le firmware approprié ou lancez la détection automatique.
  • Déplacez le cavalier BOOT0 vers la droite (position programmation) :

  • Appuyez sur le bouton reset du banc de test.
  • Appuyez sur le bouton [Flash Firmware].
  • Une fois le chargement terminé, remettez le cavalier BOOT0 vers la gauche (position normale) :

  • Appuyez sur le bouton reset pour redémarrer le banc en mode normal.

3. Bancs de test à base d'ESP32

  • Branchez le câble USB.
  • Choisissez le firmware approprié ou lancez la détection automatique.
  • Appuyez et maintenez le bouton du haut :

  • Appuyez brièvement sur le bouton du bas puis relâchez-le tout en maintenant le bouton du haut enfoncé :

  • Relâchez enfin le bouton du haut.
  • Appuyez sur le bouton [Flash Firmware].
⚠ REMARQUE IMPORTANTE
Ne débranchez jamais le câble durant l'opération de flashage. Cela corromprait la mémoire du microcontrôleur.
