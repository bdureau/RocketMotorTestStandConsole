Configure Test Stand Application

The configuration settings are grouped into a single accessible screen.

General Settings

Application Language: Displays current language setting (currently follows the Android system language automatically).

Graph Color: Defines the stroke color used to plot motor thrust curves.

Application Units: Toggles measurement units between Metric (Newtons, grams) and Imperial (lbf, ounces).

Graph Background Color: Sets the background color of the chart view. Ensure it contrasts sufficiently with the plot curve color!

Font Size: Adjusts text size across graphs and console displays for optimal readability.

Baud Rate: Sets the serial communication speed for direct USB OTG cable connections (must match the test stand board speed, typically 38400 baud).

Connection Type: Selects between Bluetooth (short-range) and USB (direct OTG cable or long-range 3DR / LoRa radio modems).

Graphics Library: Allows switching between rendering engines. Note: On Android 8.0 and above, you must select the MPAndroidChart library to prevent application crashes.

⚠ USB CONFIGURATION WARNING
Full USB Support: Enable this option only when connected directly via a USB cable. Keep disabled when using wireless long-range telemetry modules (LoRa / 3DR) to prevent EEPROM configuration corruption.

Saving Changes

Whenever you are done, click on [Save] to apply and store your new parameters. You can also exit without saving or restore factory default settings via the menu options.
