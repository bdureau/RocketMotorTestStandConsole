Choix du module Bluetooth

Vous serez amené à choisir un module Bluetooth si aucun n'a été sélectionné ou si vous voulez vous connecter à un banc de test différent.

Procédure d'appairage et de sélection

  1. Appairage système : Vous devez d'abord appairer tous les modules Bluetooth de vos bancs de test dans les réglages Bluetooth de votre appareil Android (le code PIN par défaut est généralement 1234 ou 0000).
  2. Sélection : Dans la liste des modules configurés, sélectionnez celui utilisé par votre banc de test actif.
  3. Reconnexion : Quittez l'écran et connectez-vous à nouveau. Si vous avez choisi le mauvais module ou si le banc de test est hors tension, la connexion ne s'établira pas.
⚠ CONSEIL IMPORTANT
Faites attention à bien différencier et renommer vos adaptateurs Bluetooth sur votre téléphone de manière à toujours vous connecter au bon banc de test.
