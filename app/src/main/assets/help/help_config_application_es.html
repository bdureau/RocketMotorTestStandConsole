Configuración de la aplicación Test Stand

Todos los parámetros de configuración se encuentran organizados en una única pantalla.

Parámetros Generales

Idioma de la aplicación: Muestra el idioma activo (por ahora no seleccionable, ya que sigue automáticamente el idioma del teléfono).

Color del gráfico: Ajusta el color del trazo de las curvas de empuje del motor.

Unidades de la aplicación: Alterna entre el sistema métrico (Newtons, gramos) e imperial (libras-fuerza, onzas).

Color de fondo del gráfico: Configura el color de fondo de la gráfica. ¡Asegúrese de que contraste notablemente con el color de la curva!

Tamaño de fuente: Ajusta el tamaño del texto para una lectura óptima en gráficos y pantallas.

Velocidad en baudios (Baud rate): Configuración para conexión por cable USB (debe coincidir con la velocidad de la placa del banco de pruebas, habitualmente 38400 baudios).

Tipo de conexión: Permite seleccionar entre Bluetooth (corta distancia) o USB (cable directo o radioenlaces de larga distancia).

Biblioteca de gráficos: Permite alternar entre dos motores de renderizado. Atención: en dispositivos con Android 8 o superior, debe utilizar obligatoriamente la biblioteca MPAndroidChart para evitar cierres inesperados.

⚠ ADVERTENCIA DE CONFIGURACIÓN USB
Soporte USB completo: Habilítelo únicamente si se conecta mediante cable directo USB. Manténgalo desactivado si utiliza módulos de radio de largo alcance (LoRa o 3DR) para evitar corromper la configuración de su banco de pruebas.

Guardar cambios

Cuando haya finalizado, pulse en [Guardar] para aplicar las modificaciones. También puede salir sin guardar o restablecer los valores de fábrica predeterminados.
