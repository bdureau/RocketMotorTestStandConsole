Guida per la schermata delle curve di spinta

La sezione relativa alle curve di spinta è suddivisa in 2 schermate dedicate:

Vista delle curve: Traccia tutte le curve di spinta del motore. In questa schermata è possibile scegliere quali curve visualizzare (attualmente solo la spinta, con supporto alla pressione di camera previsto in aggiornamenti futuri).

Informazioni sulla curva: Mostra un riepilogo dettagliato della curva di spinta attiva (spinta massima, impulso totale, tempo di combustione). Consente inoltre di esportare tutti i dati registrati in formato CSV.

Suggerimento per l'esportazione : Il file CSV generato può essere importato su fogli di calcolo o programmi di analisi per esaminare in dettaglio le prestazioni del motore.
