Fichier d'aide pour Banc de Test Moteur

Ceci est une aide rapide pour utiliser votre application Test Stand sur Android. Cette console est très pratique pour reconfigurer votre banc d'essai et enregistrer vos courbes de poussée directement sur le terrain.

Configuration initiale et appairage Bluetooth

  1. Compatibilité du firmware : Assurez-vous que votre banc de test est compatible (c'est-à-dire que le bon firmware y a été flashé).
  2. Connexion du module : Vérifiez que le module Bluetooth est correctement raccordé à la carte du banc d'essai.
  3. Appairage système : Ouvrez les paramètres de votre appareil Android, rendez-vous dans les réglages Bluetooth et recherchez les modules HC-05, HC-06 ou équivalents. Saisissez le code PIN d'association (par défaut 1234).
⚠ ATTENTION
Il est vivement conseillé de renommer clairement chaque adaptateur Bluetooth sur votre téléphone afin d'être certain de configurer le bon banc d'essai.
  1. Mise sous tension : Allumez le banc de test et attendez qu'il cesse d'émettre des bips sonores.
  2. Connexion : Démarrez l'application Android, touchez « Montrer les périphériques » et sélectionnez votre module HC-05 ou HC-06. L'application établit alors la liaison.

Lorsque le message « Connecté » s'affiche, la liaison est active : vous pouvez modifier les réglages du banc d'essai ou télécharger les courbes de poussée enregistrées. En cas d'échec, vérifiez l'alimentation de la carte et le module sélectionné.

Utilisation de l'application Test Stand

Commandes de l'écran principal

[Config Banc de Test Moteur]

Lit la configuration actuelle du banc de test et permet de modifier les paramètres.

[Chargement Courbes de Poussées]

Télécharge l'ensemble des courbes de poussée enregistrées en mémoire et trace les graphiques correspondants.

[Télémétrie]

Affiche les flux de télémétrie en temps réel provenant du banc d'essai.

[Réinit Config]

Restaure les paramètres d'usine du banc d'essai et permet également d'effacer toutes les courbes de poussée enregistrées.

[État]

Ouvre l'écran de diagnostic matériel pour contrôler l'état des capteurs, la tension d'alimentation et la calibration.

[Flash Firmware]

Permet de mettre à jour le firmware de la carte via un câble USB.

[Connexion / Déconnexion]

Établit ou interrompt la liaison de communication avec le banc d'essai.

Menu de l'écran principal

Depuis le menu d'options, vous pouvez ouvrir ce guide d'aide, consulter l'écran « À propos » contenant les informations de version logicielle et personnaliser le thème visuel de l'interface.

Matériels compatibles

L'application est compatible avec les cartes de banc d'essai suivantes :

• Banc de test avec ATmega328

• Banc de test avec STM32 (Version 1)

• Banc de test avec STM32 (Version 2)
