Bluetooth Module Configuration

In order for your Bluetooth module to connect your altimeter to your phone, you will first need to configure it so that it works at the same speed as your altimeter board.

This utility enables you to configure compatible modules such as the HC-05, HC-06, etc.

Required Hardware

  • A USB-to-TTL serial adapter cable.
  • A USB adapter (USB-C or Micro-USB depending on your Android device).
  • A JST adapter and matching JST cables.

Baud Rate Alignment

You will need to configure the module so that it works with your altimeter board. Note that these modules usually come preset to work at 9600 baud. However, your altimeter board by default will work at 38400 baud, so you need to make sure that you are connecting at the correct speed.

⚠ CAUTION
Make sure that you do not unplug the module or disconnect the cable while performing the configuration steps below.

Configuration Procedure

  1. Hardware Connection: Connect the Bluetooth module to your Android device using the TTL cable and USB-OTG adapter.
  2. Select Module Type: Select the Bluetooth module model you have. If you do not know which one you have, select the default one or any other compatible profile. If none work, send pictures and references of your module to support.
  3. Retrieve Configuration: Tap [Retrieve cfg]. The application will attempt to connect using 38400 baud. If it fails, try again; it will scan through various standard baud rates until synchronization is achieved and current settings are loaded.
  4. Save Configuration: Change the desired parameters such as module name, PIN, or speed. Ensure you have selected a baud rate that works with your board (typically 38400 baud) and tap [Save cfg]. If an error occurs, the save process will safely abort.
Note: Repeat this configuration procedure individually for each Bluetooth module you wish to configure.
