Configure Test Stand

The Test Stand configuration is split across 2 different screens. When opening these screens, the application connects to the Test Stand board and retrieves the configuration stored in onboard memory.

Connection Status: Ensure the Test Stand board is powered on and connected via Bluetooth or USB before updating parameters.

Test Stand Configuration (Page 1)

Baud Rate: Allows changing the Test Stand serial communication speed (reboot required).

Test Stand Resolution: Sampling rate and measurement resolution (number of samples per second).

EEPROM Size: Defines onboard flash/memory storage capacity.

Recording Duration: Maximum recording duration in seconds for motor thrust curves.

Battery Type: Defines the battery chemistry used, enabling low voltage warning alerts on supported boards.

Test Stand Configuration (Page 2)

  • Firmware Info: Retrieves and displays the Test Stand firmware version and hardware model.
  • Test Stand Units: Allows selecting measurement units (Metric or Imperial).
  • Sensor Calibration: Allows calibration of the load cell / thrust sensor using a certified known weight.
