Ajuda do banco de ensaio

Esta é uma ajuda rápida para usar o aplicativo Test Stand. O aplicativo Test Stand é uma forma muito prática de registrar as curvas de empuxo dos seus motores diretamente em campo.

Configuração inicial e pareamento Bluetooth

  1. Compatibilidade do firmware: Verifique se a placa do seu banco de ensaio é compatível (ou seja, se o firmware correto foi gravado).
  2. Conexão do módulo: Verifique se o módulo Bluetooth está conectado à placa do banco de ensaio.
  3. Pareamento no sistema: Abra as configurações do seu dispositivo Android, acesse as configurações de Bluetooth e procure o módulo HC-05, HC-06 ou outro módulo Bluetooth. Digite o código PIN de pareamento (padrão 1234).
⚠ ATENÇÃO
Dê um nome claro a cada dispositivo Bluetooth pareado no seu telefone para ter certeza de que está configurando o banco de ensaio correto.
  1. Ligar: Ligue o banco de ensaio e aguarde até que ele pare de apitar.
  2. Conectar: Abra o aplicativo no seu dispositivo Android, toque em “Mostrar dispositivos pareados” e selecione seu módulo HC-05 ou HC-06. O console tentará então se conectar.

Depois de conectado, você pode usar o aplicativo para configurar o banco de ensaio ou ler as curvas de empuxo registradas. Se não conseguir conectar, verifique se a placa está ligada e se o adaptador Bluetooth correto está selecionado.

Usando o aplicativo Test Stand

Ações da tela principal

[Configurações do Banco de Ensaio]

Lê a configuração atual do banco de ensaio e permite alterá-la.

[Ler Curvas de Empuxo]

Lê da memória todas as curvas de empuxo registradas e as exibe como gráficos interativos.

[Telemetria]

Abre a telemetria em tempo real do banco de ensaio.

[Redefinir Configurações]

Restaura os parâmetros de fábrica. Também permite apagar todas as curvas de empuxo armazenadas.

[Status]

Abre a tela de diagnóstico do hardware, que mostra o estado dos sensores, a tensão da bateria e o estado da placa.

[Atualizar Firmware]

Permite atualizar o firmware da placa diretamente por um cabo USB.

[Conectar / Desconectar]

Estabelece ou encerra a comunicação com o banco de ensaio.

Menu da tela principal

No menu de opções, você pode abrir este guia de ajuda, acessar a tela “Sobre”, que mostra as informações de versão, e personalizar a aparência do aplicativo.

Hardware compatível

Este aplicativo é compatível com as seguintes placas de banco de ensaio:

• Banco de ensaio ATmega328

Este é o protótipo original do banco de ensaio, que fiz com um ATmega328.

• Banco de ensaio STM32 (versão 1)

Este é o primeiro banco de ensaio de produção, com uma placa STM32. Ele tem apenas uma entrada para o sensor de força (célula de carga), portanto só consegue medir o empuxo.

• Banco de ensaio STM32 (versão 2)

Esta é a segunda versão do banco de ensaio, também com uma placa STM32. Ela tem uma entrada para o sensor de força para medir o empuxo e 2 entradas analógicas para medir a pressão dentro do corpo do motor.

• Banco de ensaio ESP32 (versão 3)

Esta é a terceira versão do banco de ensaio, que usa um chip ESP32. Ela tem uma entrada para o sensor de força para medir o empuxo e 2 entradas analógicas para medir a pressão dentro do corpo do motor. Observe que, por algum motivo, ela registra menos
